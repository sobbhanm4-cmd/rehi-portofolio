# راهنمای رزرو اختصاصی RN — FastAPI

ظاهر آبی آسمانی و محتوای پرتفولیو حفظ شده است. زبان سایت انگلیسی مانده تا با مخاطب و گزینه‌های دلاری هماهنگ باشد.

## امکانات

- انتخاب تاریخ و ساعت جلسه ۳۰ دقیقه‌ای؛ ساعت مرجع دبی و نمایش معادل ساعت در منطقه زمانی دستگاه بازدیدکننده.
- دریافت نام، ایمیل، واتس‌اپ، نقش، وضعیت تولید محتوا، بودجه ماهانه، یادداشت و رضایت تماس.
- همه بودجه‌ها پذیرفته می‌شوند؛ هیچ مشتری براساس پاسخ‌ها خودکار رد نمی‌شود.
- ذخیره در دیتابیس و نمایش در پنل خصوصی؛ وضعیت اولیه requested است و ساعت از همان لحظه نگه داشته می‌شود.
- جلوگیری از رزرو هم‌زمان یک ساعت و جلوگیری از ثبت دوباره همان درخواست بعد از خطای شبکه.
- پنل در `/admin.html` یا `/admin`: تعیین زمان‌های آزاد، دیدن پاسخ‌ها، تغییر وضعیت، افزودن لینک Google Meet و لغو رزرو.
- روزهای تنظیم‌نشده بسته می‌مانند. بازه رزرو از یک ساعت آینده تا ۹۰ روز آینده است.
- لغو رزرو ساعت را آزاد می‌کند. رزرو لغوشده دوباره فعال نمی‌شود؛ باید رزرو جدید ساخت.

## راه‌اندازی واقعی روی Vercel

۱. ZIP را استخراج کن. ریشه پروژه همان پوشه‌ای است که app.py و requirements.txt داخلش هستند؛ نه پوشه public.

۲. یک دیتابیس PostgreSQL در Neon یا Supabase بساز. از بخش Storage / Marketplace در Vercel نیز می‌توان آن را متصل کرد. در SQL Editor دیتابیس، محتوای `schema.sql` را یک بار اجرا کن تا جدول‌ها ساخته شوند. راه جایگزین: با DATABASE_URL تنظیم‌شده در ترمینال، `python init_db.py` را اجرا کن.

۳. سورس را در GitHub قرار بده و در Vercel گزینه Import Project را بزن؛ یا از ریشه پروژه با Vercel CLI دستور `vercel` اجرا کن. فریم‌ورک FastAPI است. تنظیمات Build و Output را روی پیش‌فرض نگه دار؛ Output Directory را به public تغییر نده.

۴. در Settings → Environment Variables این دو مقدار را اضافه کن:

| نام | مقدار |
| --- | --- |
| DATABASE_URL | رشته اتصال PostgreSQL، مانند `postgresql://USER:PASSWORD@HOST/DATABASE?sslmode=require` |
| ADMIN_PASSWORD | رمز خصوصی تصادفی با حداقل ۲۴ کاراکتر |

اگر Marketplace متغیری با نام دیگری ساخت، رشته اتصال مناسب PostgreSQL را به نام DATABASE_URL هم تنظیم کن. آدرس HTTPS یا API key مناسب این متغیر نیست. اطلاعات اتصال و رمز را در فایل‌های public نگذار.

برای ساخت رمز:
```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

۵. Deploy کن. پس از تغییر متغیرها Redeploy لازم است. وارد `https://YOUR-SITE.vercel.app/admin.html` شو؛ رمز را وارد کن، یک تاریخ آینده و چند ساعت انتخاب کن و Save بزن.

۶. در سایت عمومی همان تاریخ را انتخاب و رزرو آزمایشی ثبت کن. در پنل تب Bookings را باز کن و Refresh بزن. پس از بررسی، رزرو آزمایشی را لغو کن. این بررسی باید روی حساب واقعی تو هم انجام شود؛ نسخه تحویلی محلی تست شده و هنوز روی حساب تو منتشر نشده است.

SQLite فقط برای تست محلی است و روی Vercel پذیرفته نمی‌شود. پلن و هزینه سرویس‌ها به حساب انتخابی تو بستگی دارد. برای Preview بهتر است دیتابیس آزمایشی جداگانه تنظیم شود.

## لینک جلسه و تماس با مشتری

برای هر درخواست یک Google Meet بساز، لینک را در پنل ذخیره کن و با لینک WhatsApp داخل کارت یا ایمیل، اطلاعات جلسه را برای مشتری بفرست. تغییر وضعیت و لغو پیام خودکار نمی‌فرستند؛ خودت اطلاع بده.

این نسخه ساخت خودکار Meet، ارسال خودکار ایمیل و همگام‌سازی Google Calendar ندارد. جلسه‌های خارج از سایت خودکار مسدود نمی‌شوند؛ زمان آن‌ها را در Availability ببند. تنظیمات Google service account نسخه قدیمی دیگر لازم نیست. اگر نسخه قبلی واقعاً رزرو داشته، رزروهای قدیمی خودکار منتقل نمی‌شوند؛ قبل از بازکردن ساعت‌ها، تداخل‌های قبلی را دستی مسدود کن.

رمز پنل فقط در حافظه صفحه است و با رفرش خارج می‌شوی. روی سایت واقعی از HTTPS استفاده کن. ورود ناموفق و ارسال فرم محدودیت تعداد درخواست دارند. سیاست حذف دوره‌ای داده مشتریان هنوز تنظیم نشده؛ نگهداری و حذف را مطابق نیاز کسب‌وکارت مدیریت کن.

## لینک ویدیوها

ویدیوها Public یا Unlisted باشند و Embed فعال باشد. Private برای بازدیدکننده عمومی قابل پخش نیست. محدودیت سنی یا محدودیت Embed ممکن است مانع پخش شود.

این ۹ لینک را با برچسب بفرست، یا در `public/content.js` وارد کن:

| برچسب | محل | فیلد |
| --- | --- | --- |
| معرفی | ویدیوی بالای سایت | hero.src |
| داستان من | Our Story | story.src |
| سؤال ۱ | Who’s this perfect for? | faq[0].src |
| سؤال ۲ | What do you actually handle for me? | faq[1].src |
| سؤال ۳ | How much of my time does this take? | faq[2].src |
| سؤال ۴ | Will you post on my accounts directly? | faq[3].src |
| سؤال ۵ | How fast will I see results? | faq[4].src |
| سؤال ۶ | What does it cost? | faq[5].src |

لینک معمولی watch، لینک کوتاه youtu.be، Shorts و embed پذیرفته می‌شود. ویدیو داخل پروژه کپی نمی‌شود؛ فقط تصویر بندانگشتی قبل از کلیک بارگیری می‌شود و پلیر بعد از کلیک ساخته می‌شود. یوتیوب ممکن است تبلیغ یا پیشنهاد ویدیو نشان دهد. بخش Results فعلاً برای تصاویر نتایج است و تغییر نکرده است.

## دامنه

بعد از Deploy، در Settings → Domains دامنه خریداری‌شده را اضافه کن. رکورد DNS را دقیقاً مطابق مقادیر همان پروژه وارد کن. یکی از دامنه اصلی و www را به دیگری هدایت کن. خرید دامنه برای تست ضروری نیست؛ آدرس vercel.app هم کار می‌کند.

## اجرای محلی

```bash
python -m venv .venv
# macOS / Linux:
source .venv/bin/activate
# Windows PowerShell instead:
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

فایل `.env.example` فقط الگوست و خودکار خوانده نمی‌شود. برای اجرای محلی DATABASE_URL لازم نیست؛ SQLite ساخته می‌شود. ADMIN_PASSWORD را در محیط ترمینال تنظیم کن (حداقل ۲۴ کاراکتر)، سپس:

```bash
python init_db.py
uvicorn app:app --reload
```

سایت: `http://127.0.0.1:8000`؛ پنل: `http://127.0.0.1:8000/admin.html`.
